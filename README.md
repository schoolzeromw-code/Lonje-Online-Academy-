# LONJEZO ONLINE ACADEMY (LOA)

LONJEZO ONLINE ACADEMY (LOA) is a full-featured online learning platform built with **Node.js**, **Express**, **PostgreSQL**, **React.js**, **TailwindCSS**, and **Socket.io**. It allows students to enroll in courses, submit assignments, track progress, and receive real-time notifications. Teachers can create courses and assignments, grade submissions, and view analytics.

---

## **Features**

### **For Students**
- Register and login
- Enroll in courses
- Submit assignments (text and file uploads)
- View grades and progress
- Real-time notifications for assignments and grades

### **For Teachers**
- Register and login
- Create courses and assignments
- View student submissions
- Grade assignments with real-time notifications
- Course-level and assignment-level analytics

### **Shared Features**
- Role-based dashboards
- Blue & gold branding
- Responsive design
- Real-time updates with Socket.io
